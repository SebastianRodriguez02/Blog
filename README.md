*# 📝 Blog Concierto

## 📖 Descripción del Proyecto
Este repositorio contiene el código fuente de mi primer Blog estático. Es un proyecto de desarrollo Front-End centrado en la creación de una interfaz web estructurada y visualmente agradable.

🔗 **[Visita el proyecto en vivo haciendo clic aquí](https://sebastianrodriguez02.github.io/Blog/)**

## 📚 Historia y Contexto
Este proyecto fue desarrollado como parte de un curso práctico que realicé en **Udemy**, donde seguí la estructuración y el diseño paso a paso mediante explicaciones en video.

El objetivo principal fue construir una página desde cero para consolidar mis bases prácticas, aplicando maquetación, semántica web y estilos visuales, logrando un resultado limpio sin depender de frameworks o plantillas externas. 

## 🔨 Estructura y Funcionalidades

El proyecto destaca por su construcción técnica enfocada en el Front-End:
* **Sección de Publicaciones (Blog):** Un espacio maquetado correctamente para alojar artículos o entradas con título y contenido.
* **Maquetación Semántica:** Uso correcto de etiquetas HTML5 para organizar el contenido de forma lógica y accesible.
* **Estilizado con CSS Puro:** Implementación de estilos, distribución de elementos, paletas de colores y tipografías personalizadas.
* **Navegación Estática:** Estructura básica de menú funcional sin el uso de JavaScript.

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3
* SCSS
* JavaScript
